PORTFÓLIO — PROFESSOR JEOVANNE
Centro Educa Mais Dom Ungarelli

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP.
2. Abra o Visual Studio Code.
3. Selecione File > Open Folder (Arquivo > Abrir Pasta) e escolha a pasta portfolio_professor_jeovanne.
4. Abra o arquivo index.html.
5. Para visualizar, clique com o botão direito em index.html e escolha "Open with Live Server" se a extensão Live Server estiver instalada. Também é possível abrir o index.html diretamente no navegador.

ESTRUTURA
- index.html: conteúdo e estrutura do site.
- css/style.css: aparência, cores, layout e responsividade.
- js/script.js: menu móvel e destaque de navegação.
